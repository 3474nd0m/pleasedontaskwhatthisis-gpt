THE MIDNIGHT INDEX
==================

A self-contained responsive website made with plain HTML, CSS, and JavaScript.
No dependencies, build tools, tracking, or external network requests.

PREVIEW
-------
Open index.html in a browser.

PUBLISH WITH GITHUB PAGES (iPad-friendly)
-----------------------------------------
1. In Safari, visit https://github.com/new and sign in (or create an account).
2. Create a repository named midnight-index. For the simplest setup, make it Public.
3. On the repository page, choose Add file -> Create new file.
4. Name the file exactly: index.html
5. Open the supplied index.html, copy all its contents, then paste them into GitHub's editor.
6. Choose Commit changes.
7. Open the repository's Settings -> Pages.
8. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
9. After deployment, the URL should be https://YOUR-GITHUB-USERNAME.github.io/midnight-index/

NOTES
-----
- index.html must be at the repository root.
- GitHub Pages is public hosting: do not put private information in the repository.
- This package is the website; it is not already published online.
